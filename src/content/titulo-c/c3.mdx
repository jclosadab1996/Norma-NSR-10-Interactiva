import { TMN_FRACCIONES, BARRAS_METRICAS, BARRAS_PULGADA, buscarBarra } from '../../data/materialesConcreto';
import { cloruroPorcentajeCemento } from '../../lib/nsr10/durabilidad';
import { requisitoDeClase } from '../../data/durabilidad';

export const ej1 = (() => {
  const separacionEncofrado = 250; // mm, menor separación entre lados del encofrado
  const alturaLosa = 150; // mm
  const separacionLibre = 40; // mm, separación libre mínima entre barras
  const a = separacionEncofrado * TMN_FRACCIONES.encofrado;
  const b = alturaLosa * TMN_FRACCIONES.alturaLosa;
  const c = separacionLibre * TMN_FRACCIONES.separacionLibreBarras;
  return { separacionEncofrado, alturaLosa, separacionLibre, a, b, c, limite: Math.min(a, b, c) };
})();

export const ej2 = (() => {
  const cemento = 380; // kg/m³
  const agua = 190; // kg/m³
  const clAgua = (agua * 250e-6); // 250 mg/L ≈ 250 mg/kg → kg de Cl-
  const agregados = 1800; // kg/m³
  const clAgregados = agregados * 0.0001; // 0.01 % en masa
  const clCemento = cemento * 0.0001; // 0.01 %
  const aditivo = 3; // kg/m³
  const clAditivo = aditivo * 0.005; // 0.5 %
  const aportes = [clAgua, clAgregados, clCemento, clAditivo];
  const total = aportes.reduce((a, b) => a + b, 0);
  const pct = cloruroPorcentajeCemento(aportes, cemento);
  const c0 = requisitoDeClase('C0').cloruro;
  const c1 = requisitoDeClase('C1').cloruro;
  const c2 = requisitoDeClase('C2').cloruro;
  return { cemento, agua, clAgua, agregados, clAgregados, clCemento, aditivo, clAditivo, total, pct, c0, c1, c2 };
})();

## Idea central del capítulo

El concreto estructural es tan bueno como sus ingredientes. El Capítulo C.3 no diseña nada: **fija con qué materiales se puede construir** y cómo se comprueba que lo que llega a la obra es lo que se especificó.

1. **Cada material remite a una norma técnica** (NTC del ICONTEC o, si no existe, ASTM, AWS, AASHTO, ACI): cementantes (C.3.2), agregados (C.3.3), agua (C.3.4), acero (C.3.5) y aditivos (C.3.6).
2. **El acero tiene el régimen más estricto**: el refuerzo debe ser corrugado (el liso solo en casos puntuales), las barras corrugadas son de acero de baja aleación según NTC 2289 y los ensayos de laboratorio deben certificarse (C.3.5.10).
3. **Hay límites geométricos**: el tamaño máximo nominal del agregado grueso depende del encofrado, del espesor de la losa y de la separación del refuerzo (C.3.3.2).
4. **Los cloruros preocupan**: el agua y los aditivos no deben aportar cloruros perjudiciales al concreto preesforzado ni con aluminio embebido (C.3.4.2 y C.3.6.4).
5. **Las normas citadas hacen parte del Reglamento** (C.3.8): son obligatorias como si estuvieran reproducidas en él.

<Callout tipo="importante" titulo="Quién controla la calidad">
Si la edificación requiere Supervisión Técnica (Ley 400 de 1997), el Supervisor Técnico establece el programa de control de calidad; si no la requiere, el **constructor** debe realizar y **documentar** los controles de calidad de los materiales (<NormaRef s="C.3.1.1" pag="C-25" />). Los registros deben estar disponibles durante toda la obra (<NormaRef s="C.3.1.3" pag="C-25" />).
</Callout>

## C.3.1 — Ensayos de materiales

- **C.3.1.1.** Los materiales deben ensayarse sobre **muestras representativas** para asegurar que tienen la calidad especificada. Con Supervisión Técnica, el supervisor fija el programa de control según A.1.3.9, el Título C y el Título I; sin ella, el constructor cumple el Artículo 19 de la Ley 400 y documenta los controles (<NormaRef s="C.3.1.1" pag="C-25" />).
- **C.3.1.2.** Los ensayos se hacen según las **NTC** del ICONTEC listadas en C.3.8; si no hay NTC, según ASTM, AWS, AASHTO, PTI o ACI. Esas normas hacen parte del Reglamento (<NormaRef s="C.3.1.2" pag="C-25" />; la obligatoriedad se trata en C.1.5).
- **C.3.1.3.** El **registro completo** de ensayos de materiales y del concreto debe estar disponible para revisión durante la obra y conservarse según el Título I (<NormaRef s="C.3.1.3" pag="C-25" />).

## C.3.3 — Agregados

### C.3.3.1 — Normas

Los agregados deben cumplir **NTC 174 (ASTM C33)** si son de peso normal y **NTC 4045 (ASTM C330)** si son livianos. Se admiten agregados que, por ensayos o por experiencia práctica, hayan demostrado producir concreto de resistencia y durabilidad adecuadas, **siempre que los apruebe el Supervisor Técnico** (<NormaRef s="C.3.3.1" pag="C-26" />).

### C.3.3.2 — Tamaño máximo nominal del agregado grueso

El tamaño máximo nominal del agregado grueso no debe ser mayor que (<NormaRef s="C.3.3.2" pag="C-26" />):

<Ecuacion num="C.3.3.2 (a)-(c)" titulo="Límites del tamaño máximo nominal (TMN)">

$$
\text{TMN} \le \min\left(\tfrac{1}{5}\,s_{\text{encofrado}},\;\; \tfrac{1}{3}\,h_{\text{losa}},\;\; \tfrac{3}{4}\,s_{\text{libre}}\right)
$$

- $s_{\text{encofrado}}$: menor separación entre los lados del encofrado.
- $h_{\text{losa}}$: espesor (altura) de la losa.
- $s_{\text{libre}}$: espaciamiento libre mínimo entre barras o alambres individuales, paquetes de barras, tendones individuales, paquetes de tendones o ductos.

</Ecuacion>

Estas limitaciones **se pueden omitir** si, a juicio del profesional facultado para diseñar, la trabajabilidad y los métodos de compactación permiten colocar el concreto **sin hormigueros, vacíos ni segregación**.

<Ejemplo numero={1} titulo="Escoger el tamaño máximo del agregado">

Una viga se funde con un encofrado cuyos lados están a 250 mm; forma parte de una losa de 150 mm de espesor y la **separación libre mínima** entre las barras longitudinales es de 40 mm. ¿Qué TMN de agregado puede usarse? (Datos hipotéticos del autor.)

<Paso titulo="Límite por el encofrado" ref="C.3.3.2(a)">
$\tfrac{1}{5} \times$ {ej1.separacionEncofrado} mm = **{ej1.a.toFixed(1)} mm**.
</Paso>
<Paso titulo="Límite por la altura de la losa" ref="C.3.3.2(b)">
$\tfrac{1}{3} \times$ {ej1.alturaLosa} mm = **{ej1.b.toFixed(1)} mm**.
</Paso>
<Paso titulo="Límite por el refuerzo" ref="C.3.3.2(c)">
$\tfrac{3}{4} \times$ {ej1.separacionLibre} mm = **{ej1.c.toFixed(1)} mm**.
</Paso>
<Paso titulo="Gobierna el menor" ref="C.3.3.2">
El mínimo es {ej1.limite.toFixed(1)} mm (lo fija la separación entre barras). Con las gradaciones comunes de agregado grueso se usaría un TMN de **19 mm (3/4″)**, que cumple; uno de 25 mm no (sin la excepción del profesional diseñador).
</Paso>
<Resultado>
TMN máximo = {ej1.limite.toFixed(1)} mm → agregado de 19 mm. Si la mezcla es muy trabajable y se compacta bien, el diseñador podría aceptar uno mayor, pero debe justificarlo.
</Resultado>
</Ejemplo>

## C.3.4 — Agua

- **C.3.4.1.** El agua de mezclado debe cumplir **NTC 3459 (BS 3148)** o **ASTM C1602M** cuando esta sea menos exigente que la NTC 3459 (<NormaRef s="C.3.4.1" pag="C-26" />).
- **C.3.4.2.** El agua de mezclado para **concreto preesforzado** o con **elementos de aluminio embebidos** —incluida la humedad libre de los agregados— no debe contener cantidades perjudiciales de **iones cloruro** (<NormaRef s="C.3.4.2" pag="C-26" />; véase C.4.3.1).

## C.3.5 — Acero de refuerzo

### C.3.5.1 — Tipos de refuerzo permitidos

- El refuerzo debe ser **corrugado**.
- El refuerzo **liso** solo puede usarse en **estribos, espirales o tendones** y en **refuerzo de repartición y temperatura**.
- Cuando el Título C lo permita: pernos con cabeza para cortante, perfiles de acero estructural o tubos, o elementos tubulares de acero.
- Las **fibras de acero deformadas dispersas** se permiten solo para resistir cortante en las condiciones de C.11.4.6.1(f) (<NormaRef s="C.3.5.1" pag="C-26" />).

### C.3.5.2 — Soldadura

La soldadura de barras de refuerzo se hace según **NTC 4040 (AWS D1.4)**. La **ubicación y el tipo** de los empalmes soldados y demás soldaduras deben estar indicados en los planos o en las especificaciones. Las NTC para barras, salvo NTC 2289 (ASTM A706M), deben complementarse para exigir un informe de las propiedades del material necesarias para cumplir NTC 4040 (<NormaRef s="C.3.5.2" pag="C-26" />).

### C.3.5.3 — Refuerzo corrugado

**C.3.5.3.1 — Barras.** Las barras corrugadas deben ser de **acero de baja aleación NTC 2289 (ASTM A706M)**. Se permite acero inoxidable ASTM A955M si además cumple NTC 2289. La resistencia a la fluencia es la determinada por **ensayos sobre barras de tamaño completo**, y los esfuerzos del ensayo de tracción se calculan con el **área nominal** de las Tablas C.3.5.3-1 y C.3.5.3-2. **No se permite** acero NTC 245 ni ningún acero trabajado en frío o trefilado, salvo que lo permita explícitamente la norma de fabricación de un material permitido (<NormaRef s="C.3.5.3.1" pag="C-26" />).

**C.3.5.3.2.** Si $f_y$ es mayor que 420 MPa, la resistencia a la fluencia se toma como el esfuerzo correspondiente a una **deformación unitaria de 0.35 %** (véase C.9.4) (<NormaRef s="C.3.5.3.2" pag="C-27" />).

**C.3.5.3.3.** Las barras ASTM A1035M pueden usarse como **refuerzo transversal** en C.21.6.4 o como **espiral** en C.10.9.3 (<NormaRef s="C.3.5.3.3" pag="C-27" />).

**C.3.5.3.4.** Las **parrillas de refuerzo** cumplen NTC 2043 (ASTM A184M), y sus barras NTC 2289 (<NormaRef s="C.3.5.3.4" pag="C-27" />).

**C.3.5.3.5 — Alambre corrugado.** Cumple NTC 1907 (ASTM A496M), con tamaño **entre MD25 (5.6 mm) y MD200 (16 mm)**, salvo lo que permite C.3.5.3.7. Para $f_y > 420$ MPa vale la deformación de 0.35 %. **No se permiten alambres individuales** (corrugados o lisos) como estribos ni como refuerzo longitudinal en elementos del sistema de resistencia sísmica (<NormaRef s="C.3.5.3.5" pag="C-28" />).

**C.3.5.3.6 — Malla electrosoldada de alambre liso.** NTC 1925 (ASTM A185M); intersecciones soldadas separadas **no más de 300 mm** en el sentido del esfuerzo (excepto mallas usadas como estribos según C.12.13.2) (<NormaRef s="C.3.5.3.6" pag="C-28" />).

**C.3.5.3.7 — Malla electrosoldada de alambre corrugado.** NTC 2310 (ASTM A497M); intersecciones **no más de 400 mm**. El alambre corrugado de diámetro mayor que MD200 se permite en malla electrosoldada pero se trata como **alambre liso** para desarrollo y empalmes (<NormaRef s="C.3.5.3.7" pag="C-28" />).

**C.3.5.3.8 — Barras galvanizadas o con epóxico.** Galvanizadas: NTC 4013 (ASTM A767M). Con epóxico: NTC 4004 (ASTM A775M) o ASTM A934M. Las barras que se vayan a galvanizar o recubrir deben cumplir NTC 2289 (<NormaRef s="C.3.5.3.8" pag="C-28" />).

**C.3.5.3.9 — Alambre y malla con epóxico.** ASTM A884M (<NormaRef s="C.3.5.3.9" pag="C-28" />).

**C.3.5.3.10 — Alambre y malla de acero inoxidable.** ASTM A1022M, con las mismas restricciones de tamaño (MD25 a MD200), la deformación de 0.35 % y las separaciones de soldaduras de 300 mm (liso) y 400 mm (corrugado) (<NormaRef s="C.3.5.3.10" pag="C-28" />).

### C.3.5.4 — Refuerzo liso

El refuerzo liso solo se permite en **estribos, refuerzo de retracción y temperatura o espiral**; **no** puede ser refuerzo longitudinal de flexión, excepto en mallas electrosoldadas. Cumple NTC 161 (ASTM A615M) o los requisitos del corrugado de C.3.5.3.1 (<NormaRef s="C.3.5.4.1" pag="C-28" />). Los alambres lisos para espiral cumplen NTC 4002 (ASTM A82M) (<NormaRef s="C.3.5.4.2" pag="C-28" />).

### C.3.5.5 — Pernos con cabeza para cortante

Los pernos con cabeza y sus ensamblajes cumplen **ASTM A1044M** (<NormaRef s="C.3.5.5.1" pag="C-28" />).

### C.3.5.6 — Acero de preesfuerzo

Debe cumplir una de: alambre NTC 159 (ASTM A421M); alambre de baja relajación NTC 159; torón **NTC 2010 (ASTM A416M)**; barras de alta resistencia NTC 2142 (ASTM A722M). Se admiten otros alambres, torones o barras si se demuestra que cumplen los requisitos mínimos de esas normas y no tienen propiedades menos satisfactorias (<NormaRef s="C.3.5.6" pag="C-28" />).

### C.3.5.7 — Acero estructural, tubos o tuberías

- **Acero estructural** en elementos compuestos a compresión (C.10.13.7 o C.10.13.8): NTC 1920 (ASTM A36M), NTC 1950 (A242M), NTC 1985 (A572M), NTC 2012 (A588M) o perfiles ASTM A992M (<NormaRef s="C.3.5.7.1" pag="C-29" />).
- **Tubos rellenos de concreto** (C.10.13.6): NTC 3470 (ASTM A53M) Grado B, NTC 4526 (ASTM A500M) o NTC 2374 (ASTM A501) (<NormaRef s="C.3.5.7.2" pag="C-29" />).

### C.3.5.8 y C.3.5.9 — Fibras y barras con cabeza

Las **fibras de acero** para concreto reforzado con fibras dispersas deben cumplir NTC 5214 (ASTM A820M) y tener una relación longitud/diámetro **entre 50 y 100** (<NormaRef s="C.3.5.8" pag="C-29" />). Las **barras corrugadas con cabeza** cumplen ASTM A970M, y las interrupciones del corrugado no deben exceder $2\,d_b$ medidas desde la cara de apoyo de la cabeza (<NormaRef s="C.3.5.9" pag="C-29" />).

### C.3.5.10 — Evaluación y aceptación del acero de refuerzo

1. Deben tomarse y ensayarse **muestras representativas** con la frecuencia y el alcance del Título I, según la NTC correspondiente (<NormaRef s="C.3.5.10.1" pag="C-29" />).
2. Los ensayos deben demostrar **inequívocamente** que el acero cumple la NTC; el laboratorio **certifica la conformidad** y envía copia al **Supervisor Técnico** y al **ingeniero diseñador estructural** (<NormaRef s="C.3.5.10.2" pag="C-29" />).
3. El certificado debe contener, como mínimo (<NormaRef s="C.3.5.10.3" pag="C-29" />):

<Detalle titulo="Contenido mínimo del certificado de conformidad (C.3.5.10.3, ítems a–j)">

- (a) nombre y dirección de la obra;
- (b) fecha de recepción de las muestras y fecha de los ensayos;
- (c) fabricante y norma NTC bajo la cual se fabricó el material y se ensayó;
- (d) masa por unidad de longitud de la barra, alambre, malla o torón, su conformidad con las variaciones permitidas y su diámetro nominal;
- (e) características del corrugado, si es acero corrugado;
- (f) resultados del ensayo de tracción: resistencia a la fluencia y resistencia última, evaluadas con el área nominal de la norma NTC, y el porcentaje de alargamiento;
- (g) resultado del ensayo de doblamiento;
- (h) composición química, cuando se solicita;
- (i) conformidad con la norma de fabricación;
- (j) nombre y firma del director del laboratorio.

</Detalle>

## C.3.6 — Aditivos

- **C.3.6.1.** Reductores de agua y modificadores del fraguado: **NTC 1299 (ASTM C494M)**. Aditivos para concreto fluido: NTC 4023 (ASTM C1017M) (<NormaRef s="C.3.6.1" pag="C-30" />).
- **C.3.6.2.** Incorporadores de aire: **NTC 3502 (ASTM C260)** (<NormaRef s="C.3.6.2" pag="C-30" />).
- **C.3.6.3.** Los aditivos que no cumplan C.3.6.1 y C.3.6.2 requieren **aprobación previa del Supervisor Técnico** (<NormaRef s="C.3.6.3" pag="C-30" />).
- **C.3.6.4.** **No debe emplearse cloruro de calcio** ni aditivos con cloruros (que no provengan de impurezas) en concreto **preesforzado**, con **aluminio embebido** o fundido en **encofrados permanentes de acero galvanizado** (<NormaRef s="C.3.6.4" pag="C-30" />; véanse C.4.3.1 y C.6.3.2).
- **C.3.6.5.** Los aditivos usados con **cemento expansivo** (NTC 4578) deben ser compatibles con él y no producir efectos nocivos (<NormaRef s="C.3.6.5" pag="C-30" />).

## C.3.7 — Almacenamiento de materiales

- Los materiales cementantes y los agregados se almacenan de modo que **no se deterioren** ni se contaminen con **materia extraña** (<NormaRef s="C.3.7.1" pag="C-30" />).
- Un material **deteriorado o contaminado no debe usarse** en el concreto (<NormaRef s="C.3.7.2" pag="C-30" />).

## Errores comunes

<Callout tipo="error" titulo="Qué suele salir mal">
- **Usar acero corrugado NTC 248 / ASTM A615 «porque es el de siempre»**: según el texto de C.3.5.3.1 impreso en el PDF, las barras corrugadas deben ser NTC 2289 (ASTM A706M) y la nota de NTC 248 dice que C.3.5.3 prohíbe ese tipo de acero como corrugado. Verifica el suministro con el diseñador y el Supervisor Técnico.
- **Calcular áreas con $\pi d^2/4$** en vez de usar el área nominal de las Tablas C.3.5.3-1 y C.3.5.3-2.
- **Olvidar el límite de tamaño del agregado** frente a la separación entre barras (3/4 de la separación libre): produce hormigueros.
- **Usar cloruro de calcio** o aditivos con cloruros en concreto preesforzado o con aluminio embebido (C.3.6.4).
- **Emplear cemento de mampostería** o cementos IS (≥70) como cementante principal.
- **Usar alambres individuales como estribos** en elementos del sistema de resistencia sísmica (C.3.5.3.5).
- **Aceptar el acero sin certificado de conformidad** del laboratorio, firmado por su director (C.3.5.10).
- **Cambiar de cemento o de agregado** sin revisar la dosificación: el material de obra debe ser el que sirvió de base (C.3.2.2).
</Callout>

## Resumen en una línea

**Cada material del concreto estructural debe cumplir su norma NTC (o ASTM), el agregado debe caber entre encofrado y barras (TMN ≤ 1/5, 1/3 y 3/4 de los límites), el refuerzo es corrugado y certificado por laboratorio (NTC 2289), los cloruros se limitan en preesforzado y aluminio embebido, y todo lo citado en C.3.8 forma parte del Reglamento.**
