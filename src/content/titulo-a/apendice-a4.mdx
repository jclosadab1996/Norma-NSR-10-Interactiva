import municipios from '../../data/municipios.json';
import { coeficienteFa, coeficienteFv, coeficienteImportancia, periodosEspectro, sa, mesetaSa, zonaAmenaza } from '../../lib/nsr10';

export const pct = (x, total) => ((100 * x) / total).toFixed(1);
export const total = municipios.length;
export const porZona = ['Baja', 'Intermedia', 'Alta'].map((z) => {
  const g = municipios.filter((m) => m.zona === z);
  return { zona: z, n: g.length, aaMax: Math.max(...g.map((m) => m.aa)), avMax: Math.max(...g.map((m) => m.av)), aaMin: Math.min(...g.map((m) => m.aa)), avMin: Math.min(...g.map((m) => m.av)) };
});
export const porDep = (() => {
  const mapa = new Map();
  for (const m of municipios) {
    const d = mapa.get(m.departamento) ?? { nombre: m.departamento, n: 0, Baja: 0, Intermedia: 0, Alta: 0, aaMax: 0, avMax: 0 };
    d.n += 1;
    d[m.zona] += 1;
    d.aaMax = Math.max(d.aaMax, m.aa);
    d.avMax = Math.max(d.avMax, m.av);
    mapa.set(m.departamento, d);
  }
  return [...mapa.values()];
})();
export const masAlta = [...porDep].sort((a, b) => b.Alta - a.Alta || b.n - a.n).slice(0, 10);
export const todosAlta = porDep.filter((d) => d.Alta === d.n).map((d) => d.nombre);
export const todosBaja = porDep.filter((d) => d.Baja === d.n).map((d) => d.nombre);
export const distribucion = (campo) => {
  const mapa = new Map();
  for (const m of municipios) mapa.set(m[campo], (mapa.get(m[campo]) ?? 0) + 1);
  return [...mapa.entries()].sort((a, b) => a[0] - b[0]);
};
export const rango = (campo) => [Math.min(...municipios.map((m) => m[campo])), Math.max(...municipios.map((m) => m[campo]))];
export const topAa = municipios.filter((m) => m.aa >= 0.5);
export const aeMayorAa = municipios.filter((m) => m.ae > m.aa).length;
export const adMayorAe = municipios.filter((m) => m.ad > m.ae).length;
export const fueraTablaAe = municipios.filter((m) => m.ae > 0.28);

export const buscar = (codigo) => municipios.find((m) => m.codigo === codigo);

## Idea central del apéndice

Una frase resume por qué existe este apéndice: **los coeficientes sísmicos de diseño dependen del lugar, y esta es la tabla donde el Reglamento los publica municipio por municipio**. Para cualquier proyecto en Colombia, el primer dato que se necesita —antes de elegir sistema estructural, calcular el espectro o evaluar una edificación— sale de aquí.

A diferencia de los Apéndices A-1 a A-3, que son **recomendaciones**, el A-4 es la **fuente de datos** que usa el Reglamento: A.2.2.3 manda leer $A_a$ y $A_v$ de los municipios en este apéndice (<NormaRef s="A.2.2.3" pag="A-14" />), y A.10.3 y A.12.2 remiten a él para $A_e$ y $A_d$.

<Callout tipo="importante" titulo="Una fila, cuatro coeficientes y una zona">
Cada municipio tiene en el apéndice: su **código DANE**, $A_a$, $A_v$, la **zona de amenaza sísmica** (que no es un dato independiente: sale de $A_a$ y $A_v$ según A.2.3), $A_e$ y $A_d$. Los {total.toLocaleString('en-US').replace(',', ' ')} municipios están agrupados por **departamento**, en orden alfabético.
</Callout>

## Qué significa cada coeficiente

<TablaNorma numero="Coeficientes del Apéndice A-4" titulo="Qué representa cada columna y dónde se usa">

| Coeficiente | Qué es | Sismo de referencia | Se usa en | Rango en el apéndice |
|---|---|---|---|---|
| $A_a$ | Aceleración horizontal pico efectiva para diseño (edificios bajos, períodos cortos) | De diseño: 10 % en 50 años (475 años) | A.2.2, A.2.6 → espectro de diseño | {rango('aa')[0].toFixed(2)} a {rango('aa')[1].toFixed(2)} |
| $A_v$ | Velocidad horizontal pico efectiva para diseño, expresada como aceleración (edificios altos, períodos largos) | De diseño | A.2.2, A.2.6 → rama $1/T$ del espectro | {rango('av')[0].toFixed(2)} a {rango('av')[1].toFixed(2)} |
| $A_e$ | Aceleración pico efectiva **reducida**, para diseño con **seguridad limitada** | De seguridad limitada: 20 % en 50 años (225 años) | A.10.3 → evaluación e intervención de edificaciones existentes | {rango('ae')[0].toFixed(2)} a {rango('ae')[1].toFixed(2)} |
| $A_d$ | Aceleración pico efectiva para el **umbral de daño** | Del umbral de daño: 80 % en 50 años (31 años) | A.12.2 → espectro del umbral de daño de edificaciones de los grupos III y IV | {rango('ad')[0].toFixed(2)} a {rango('ad')[1].toFixed(2)} |

</TablaNorma>

Tres relaciones útiles para leer los datos:

- $A_a$ y $A_v$ son siempre **múltiplos de 0.05** entre 0.05 y 0.50: son los valores de la Tabla A.2.2-1, donde cada número de «región» de los mapas (1 a 10) equivale a $A = 0.05\times$ región.
- **La zona sale del mayor entre $A_a$ y $A_v$** (A.2.3): **Baja** si ambos ≤ 0.10; **Intermedia** si alguno es 0.15 o 0.20 y ninguno pasa de 0.20; **Alta** si alguno es ≥ 0.25. Los datos de la tabla cumplen esa regla en todos los municipios.
- $A_e$ y $A_d$ son valores **más bajos** que $A_a$: el sismo de seguridad limitada y el del umbral de daño son menos severos que el de diseño. En {total - aeMayorAa} de los {total} municipios $A_e \le A_a$ (en los demás es algo mayor, casi siempre 0.16 frente a 0.15, y en unos pocos casos bastante más), y $A_d \le A_e$ en {total - adMayorAe} de {total}, es decir, en todos.

## Cómo leer el apéndice

El apéndice ocupa las **páginas impresas A-153 a A-174** (PDF 197 a 218, 22 páginas) y se organiza así:

1. **Encabezado de departamento** («Departamento de Antioquia»), seguido de una cabecera de columnas: *Municipio · Código · Aa · Av · Zona de Amenaza Sísmica · Ae · Ad*.
2. **Una fila por municipio**, en orden creciente de código DANE dentro del departamento (la primera suele ser la capital: 05001 Medellín, 76001 Cali…).
3. Los departamentos van en orden alfabético, de **Amazonas** a **Vichada**. Cada uno repite la cabecera de columnas, así que una tabla puede continuar en la página siguiente sin que cambie nada.

**Procedimiento para obtener los datos de un proyecto:**

1. Identifica el **departamento y el municipio** (o el código DANE de 5 dígitos) donde se construirá.
2. Lee $A_a$ y $A_v$: con ellos y el tipo de suelo se obtienen $F_a$, $F_v$ y el espectro (Capítulo [A.2](/titulo-a/a2)).
3. La zona de amenaza condiciona los **sistemas estructurales permitidos**, el **método de análisis** y las irregularidades a evaluar (Capítulos [A.3](/titulo-a/a3) a [A.6](/titulo-a/a6)).
4. Si la edificación es **existente**, usa $A_e$ (Capítulo [A.10](/titulo-a/a10)); si es del grupo de uso **III o IV**, usa también $A_d$ para el umbral de daño (Capítulo [A.12](/titulo-a/a12)).

## Municipios que el apéndice no lista

El Apéndice A-4 corresponde a la división político-administrativa vigente al publicarse la norma (2010) y **no se actualiza** con las creaciones de municipios, cambios de nombre o de código posteriores. Además, el listado incluye como filas **áreas no municipalizadas** o corregimientos departamentales (por ejemplo Mirití-Paraná en Amazonas, o Pacoa, Papunahua y Yavarate en Vaupés) junto a los municipios.

Si el sitio de tu proyecto pertenece a una entidad territorial que no aparece, **la norma no da su valor** y este sitio tampoco lo inventa. Opciones prudentes:

- Verificar si cambió de **nombre o código** (el apéndice puede traerlo con el nombre antiguo).
- Si es un municipio **segregado de otro**, usar los valores del municipio de origen o el más desfavorable de los vecinos, justificándolo en la memoria.
- Consultar a la **autoridad municipal** y, si procede, a la Comisión Asesora Permanente (A.2.1.3 permite valores distintos con su aprobación previa).

## Errores comunes

<Callout tipo="error" titulo="Qué suele salir mal">
- **Usar los valores de otra ciudad «cercana»** o de un mapa de internet en lugar de la fila del municipio.
- **Confundir Aa con Av** al calcular el espectro: $A_a$ controla la meseta (períodos cortos) y $A_v$ la rama $1/T$.
- **Usar $A_e$ o $A_d$ para diseñar un edificio nuevo**: son para evaluar edificaciones existentes (A.10) y para el umbral de daño (A.12), no para el sismo de diseño.
- **Tomar la zona de amenaza como dato independiente**: se deduce del mayor entre $A_a$ y $A_v$; si cambias uno, recalcula la zona.
- **No documentar la fuente cuando hay discrepancias** (Montería, Villavicencio, Cúcuta, Armenia, Ibagué).
- **Ignorar que ya exista una microzonificación sísmica** del municipio.
</Callout>

## Resumen en una línea

**El Apéndice A-4 da, por municipio, $A_a$ y $A_v$ (diseño, A.2), $A_e$ (existentes, A.10), $A_d$ (umbral de daño, A.12) y la zona de amenaza que se deduce del mayor entre $A_a$ y $A_v$: la mitad de los municipios del país está en amenaza alta.**
