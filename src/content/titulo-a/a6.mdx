export const e1 = (() => {
  const aa = 0.15, av = 0.2, i = 1.0;
  const fa = coeficienteFa('D', aa) ?? NaN;
  const fv = coeficienteFv('D', av) ?? NaN;
  const p = { aa, av, fa, fv, i };
  const n = 5, hp = 3, hn = n * hp;
  const pesos = [4500, 4500, 4500, 4500, 3600]; // kN por nivel
  const niveles = pesos.map((w, idx) => ({ h: hp * (idx + 1), m: (w / 9.8) * 1000 }));
  const masaKg = niveles.reduce((s, x) => s + x.m, 0);
  const peso = pesos.reduce((a, b) => a + b, 0);
  const ta = periodoAproximado('porticos-concreto', hn);
  const per = periodosEspectro(p);
  const saT = sa(ta, p);
  const vsN = cortanteBasal(saT, masaKg);
  const dist = distribuirFuerzas(niveles, vsN, ta);
  const k = exponenteK(ta);
  const delta = [0, 15, 38, 70, 95, 112]; // mm, centro de masa, fuerzas sin dividir por R
  const limite = limiteDeriva('general');
  const pisos = niveles.map((nv, idx) => {
    const P = pesos.slice(idx).reduce((a, b) => a + b, 0);
    const V = dist[idx].cortantePiso / 1000;
    const dd = delta[idx + 1] - delta[idx];
    const Q = (P * (dd / 1000)) / (V * hp);
    const v = verificarDeriva(delta[idx + 1], delta[idx], hp * 1000, limite);
    const v7 = verificarDeriva(delta[idx + 1], delta[idx], hp * 1000, limite, 0.7);
    return { piso: idx + 1, di: delta[idx + 1], P, V, dd, Q, v, v7 };
  });
  const qMax = Math.max(...pisos.map((x) => x.Q));
  const critico = pisos.reduce((a, b) => (b.v.razon > a.v.razon ? b : a));
  return { aa, av, fa, fv, i, n, hp, hn, peso, masaKg, ta, per, saT, vs: vsN / 1000, k, dist, delta, limite, pisos, qMax, critico, limiteMamp: limiteDeriva('mamposteriaCortante') };
})();

export const pdelta = (() => {
  const P = 40000, dCm = 0.06, V = 5000, hp = 3.2; // kN, m, kN, m
  const Q = (P * dCm) / (V * hp);
  const fac = Q / (1 - Q);
  return { P, dCm, V, hp, Q, fac, dpd: dCm * 1000 * fac, mult: 1 / (1 - Q), total: dCm * 1000 * (1 + fac) };
})();

export const torsion = (() => {
  const r = 12, theta = 0.0004; // m, rad
  return { r, theta, dt: r * theta * 1000 };
})();

export const alt = (() => {
  // A.6.3-2 con hp = 3.0 m en todos los pisos (mm)
  const d2 = 70, d1 = 80, di = 92, hpi = 3.0, hp1 = 3.0;
  const extrapol = d2 + ((d1 - d2) * (hpi + hp1)) / hp1;

## Idea central del capítulo

Un edificio puede resistir las fuerzas del sismo y aun así **fallar en servicio**: si un piso se desplaza demasiado respecto al de abajo, se rompen muros, vidrios y acabados, se pierde la estabilidad global y las personas entran en pánico. El Capítulo A.6 controla ese riesgo con tres cosas:

1. **Calcular los desplazamientos** horizontales de cada piso (centro de masa, torsión y efectos de segundo orden P-Delta).
2. **Obtener la deriva**, es decir, el desplazamiento relativo entre pisos consecutivos, y compararla con un **límite** de la altura de piso (1.0 % o 0.5 %).
3. **Separar** la edificación de sus vecinas para que no se golpeen durante el sismo.

<Callout tipo="importante" titulo="Las derivas se calculan con fuerzas sin dividir por R">
La fuerza cortante de piso $V_i$ que se usa en este capítulo es la del Capítulo A.4 **"sin dividir por $R$"** (<NormaRef s="A.6.0" pag="A-73" />). Es decir, los desplazamientos de A.6 provienen de las fuerzas **elásticas**, no de las fuerzas reducidas $E = F_s/R$ con que se diseñan los elementos. Además, para edificaciones de los grupos II, III y IV se permite calcular los desplazamientos con $I = 1.0$ (<NormaRef s="A.6.2.1.2" pag="A-74" />).
</Callout>

## A.6.1 — General

- **Alcance** (<NormaRef s="A.6.1.1" pag="A-73" />): el capítulo da los procedimientos para calcular la deriva y sus límites permisibles.
- **Definición** (<NormaRef s="A.6.1.2" pag="A-73" />): deriva es el **desplazamiento horizontal relativo entre dos puntos colocados en la misma línea vertical, en dos pisos o niveles consecutivos**.
- **Por qué controlarla** (<NormaRef s="A.6.1.3" pag="A-73" />): la deriva se asocia con (a) deformación inelástica de elementos estructurales y no estructurales, (b) la estabilidad global de la estructura, (c) daño en elementos estructurales que no son del sistema de resistencia sísmica y en elementos no estructurales (divisiones, enchapes, acabados, instalaciones eléctricas y mecánicas) y (d) alarma y pánico entre los ocupantes.

La norma insiste en que es **fundamental** cumplir estrictamente estos requisitos para lograr el propósito del Reglamento y un buen comportamiento de la estructura y su contenido.

## A.6.2 — Cálculo del desplazamiento horizontal

El desplazamiento total de un punto del piso se arma con tres sumandos: el del **centro de masa**, el **adicional por torsión** y el **adicional por P-Delta**.

### A.6.2.1 — Desplazamientos en el centro de masa, δcm

Son los desplazamientos horizontales del centro de masa en las dos direcciones principales (<NormaRef s="A.6.2.1" pag="A-74" />). Si el análisis es dinámico, se combinan los modos según A.5.4.4 (primero las derivas por modo, nunca las deflexiones ya combinadas).

- **Con el método de la FHE** (<NormaRef s="A.6.2.1.1" pag="A-74" />): las fuerzas para calcular los desplazamientos pueden obtenerse con el período $T$ de la ecuación A.4.2-1 aplicando el tope $C_uT_a$, o alternativamente con el período $T$ de las ecuaciones A.4.2-3 o A.4.2-5.
- **Grupos de uso II, III y IV** (<NormaRef s="A.6.2.1.2" pag="A-74" />): para calcular los desplazamientos en el centro de masa se permite usar $I = 1.0$; las fuerzas con que se verifica la **resistencia** sí usan el $I$ del grupo de uso.

### A.6.2.2 — Desplazamientos por torsión, δt

Solo se evalúan cuando los **diafragmas son rígidos** (<NormaRef s="A.6.2.2" pag="A-74" />). El incremento de desplazamiento por la rotación del piso, en un punto cualquiera, es:

<Ecuacion num="A.6.2-1" titulo="Desplazamiento adicional por torsión">

$$
\delta_{t,j}=r_j\,\theta_i
$$

- $r_j$: proyección, perpendicular a la dirección $j$ en planta, de la distancia entre el centro de masa y el punto de interés.
- $\theta_i$: rotación (rad) del nivel $i$ alrededor del eje vertical que pasa por el centro de masa, causada por los efectos torsionales de A.3.6.7.

</Ecuacion>

<Detalle titulo="Ejemplo numérico de A.6.2-1">

Un punto de borde está a $r_j$ = {torsion.r} m del centro de masa (medido perpendicular a la dirección estudiada) y el piso rota $\theta_i$ = {torsion.theta} rad. El desplazamiento extra por torsión es $\delta_t = 12\times0.0004$ = **{f(torsion.dt, 1)} mm**, que se suma al $\delta_{cm}$ de ese punto. Por eso los **bordes** de un edificio con torsión se desplazan más que su centro de masa.

</Detalle>

### A.6.2.3 — Efectos P-Delta, δpd

Los efectos de segundo orden (la carga vertical actuando sobre la estructura ya desplazada) **aumentan** las deflexiones y las fuerzas internas. Deben considerarse cuando el **índice de estabilidad $Q_i$** supera 0.10 (<NormaRef s="A.6.2.3" pag="A-74" />):

<Ecuacion num="A.6.2-2" titulo="Índice de estabilidad del piso i">

$$
Q_i=\frac{P_i\,\Delta_{cm}}{V_i\,h_{pi}}
$$

- $P_i$: carga vertical total (muerta + viva) en el piso $i$ y todos los superiores.
- $\Delta_{cm}$: deriva del piso en el centro de masa.
- $V_i$: cortante del piso $i$ sin dividir por $R$.
- $h_{pi}$: altura del piso $i$.

</Ecuacion>

<TablaNorma numero="Criterio" titulo="Qué hacer según el valor de Qi" pag="A-74">

| Valor de $Q_i$ | Consecuencia |
|---|---|
| $Q_i \le 0.10$ | No hay que considerar efectos P-Delta |
| $0.10 < Q_i \le 0.30$ | Deben incluirse los efectos P-Delta: $\delta_{pd}$ (A.6.2-3) y fuerzas internas $\times\,1/(1-Q_i)$ (A.6.2.3.2) |
| $Q_i > 0.30$ | Estructura potencialmente **inestable**: debe rigidizarse, salvo que en estructuras de concreto reforzado se cumplan **todos** los requisitos de C.10.11.6.2(b) |

</TablaNorma>

La deflexión adicional por P-Delta en el piso $i$:

<Ecuacion num="A.6.2-3" titulo="Desplazamiento adicional por P-Delta">

$$
\delta_{pd}=\delta_{cm}\left(\frac{Q_i}{1-Q_i}\right)
$$

</Ecuacion>

Dos alternativas o complementos:

- **A.6.2.3.1**: en estructuras de concreto reforzado, los efectos P-Delta pueden evaluarse siguiendo C.10.11 (<NormaRef s="A.6.2.3.1" pag="A-75" />).
- **A.6.2.3.2**: si $Q_i > 0.10$, los efectos P-Delta en las **fuerzas internas** causadas por las cargas laterales se aumentan multiplicándolas, piso por piso, por el factor $1/(1-Q_i)$ (<NormaRef s="A.6.2.3.2" pag="A-75" />).

<Detalle titulo="Ejemplo numérico: un piso con Qi > 0.10">

Piso con $P_i$ = {miles(pdelta.P)} kN, deriva en el centro de masa $\Delta_{cm}$ = {f(pdelta.dCm, 3)} m, $V_i$ = {miles(pdelta.V)} kN y $h_{pi}$ = {f(pdelta.hp, 1)} m:

$$
Q_i=\frac{40000\times0.060}{5000\times3.2}
$$

Resulta $Q_i$ = **{f(pdelta.Q, 3)}** (> 0.10: hay que tener en cuenta P-Delta y < 0.30: no hay inestabilidad potencial). Si el desplazamiento del centro de masa es $\delta_{cm}$ = {f(pdelta.dCm * 1000, 0)} mm, el adicional es $\delta_{pd}$ = {f(pdelta.dCm * 1000, 0)} × {f(pdelta.Q, 3)}/(1 − {f(pdelta.Q, 3)}) = **{f(pdelta.dpd, 1)} mm** (el desplazamiento total pasa a {f(pdelta.total, 1)} mm) y las fuerzas internas por cargas laterales se multiplican por 1/(1 − Q) = **{f(pdelta.mult, 3)}**. La ecuación, tal como está escrita, se aplica nivel por nivel y la deriva se calcula luego con los desplazamientos totales (A.6.3.1.1).

</Detalle>

### A.6.2.4 — Desplazamientos horizontales totales

Se obtienen del análisis estructural con el método definido en A.3.4 y las rigideces de A.3.4.3, para cualquier grado de libertad, como **suma de valores absolutos** (<NormaRef s="A.6.2.4" pag="A-75" />):

<Ecuacion num="A.6.2-4" titulo="Desplazamiento horizontal total">

$$
\delta_{tot,j}=\left|\delta_{cm,j}\right|+\left|\delta_{t,j}\right|+\left|\delta_{pd,j}\right|
$$

- $\delta_{cm,j}$: desplazamiento del centro de masa en la dirección $j$.
- $\delta_{t,j}$: adicional por torsión (solo con diafragma rígido).
- $\delta_{pd,j}$: adicional por P-Delta.

</Ecuacion>

Cuando se usan procedimientos de **interacción suelo-estructura**, o cuando A.3.4.2 lo exige porque la estructura se analizó **empotrada en la base**, deben sumarse a los desplazamientos totales los adicionales obtenidos con el Capítulo A.7.

<Callout tipo="nota" titulo="Errata menor en la ecuación">
En el texto del PDF la ecuación A.6.2-4 y la frase que la acompaña escriben "$\delta_{t0t,j}$" (con un cero) donde debería decir $\delta_{tot,j}$. Es un error tipográfico evidente; la nomenclatura de A.6.0 usa $\delta_{tot,j}$.
</Callout>

## A.6.3 — Evaluación de la deriva máxima

### A.6.3.1.1 — Edificaciones sin irregularidad 1aP/1bP, o con diafragma flexible

Para edificaciones regulares o irregulares **sin irregularidad en planta tipo 1aP o 1bP** (Tabla A.3-6), o con **diafragma flexible**, la deriva máxima del piso $i$ es la mayor de las dos direcciones principales, calculada como el **valor absoluto de la diferencia** entre el desplazamiento del centro de masa del piso $i$ y el del piso inferior $(i-1)$ **incluyendo los efectos P-Delta** (<NormaRef s="A.6.3.1.1" pag="A-75" />):

$$
\Delta^i_{max}=\max_{j}\ \left|\delta^i_{cm,j}-\delta^{i-1}_{cm,j}\right|
$$

(Con $\delta_{cm}$ ya con $\delta_{pd}$ si $Q_i>0.10$. Es la expresión que la calculadora y los ejemplos usan.)

### A.6.3.1.2 — Con irregularidad torsional 1aP o 1bP

En estas edificaciones se mide la deriva en **cualquier punto** del piso, restando los desplazamientos **totales máximos** (A.6.2.4) del punto en el piso $i$ y de un punto en el mismo eje vertical del piso $i-1$ (<NormaRef s="A.6.3.1.2" pag="A-75" />), y combinando las dos direcciones:

<Ecuacion num="A.6.3-1" titulo="Deriva máxima con irregularidad torsional">

$$
\Delta^i_{max}=\sqrt{\sum_{j=1}^{2}\left(\delta^i_{tot,j}-\delta^{i-1}_{tot,j}\right)^{2}}
$$

</Ecuacion>

Alternativamente pueden usarse procedimientos para estimar máximos de cantidades vectoriales. Basta verificarla en **todos los ejes verticales de columna** y en los **bordes de los muros estructurales**; la deriva máxima del piso es la mayor de todos esos puntos (<NormaRef s="A.6.3.1.2" pag="A-76" />).

### A.6.3.1.3 — Forma alternativa en pisos superiores (A.6.3-2)

En los **pisos superiores** de ciertas edificaciones se permite calcular la deriva con una forma alternativa, siempre que se cumplan **las cinco** condiciones (<NormaRef s="A.6.3.1.3" pag="A-76" />):

| | Condición |
|---|---|
| (a) | La edificación tiene **diez o más pisos** sobre su base |
| (b) | Solo aplica en los pisos **por encima de dos tercios** de la altura de la edificación (medida desde la base) |
| (c) | El sistema de resistencia sísmica es **diferente a pórtico resistente a momentos** (p. ej. muros o dual) |
| (d) | La edificación es **regular** tanto en planta como en altura (Capítulo A.3) |
| (e) | El índice de estabilidad $Q_i$ es **menor de 0.10** en todos los pisos donde se aplicaría |

La deriva máxima del piso es la mayor de las dos direcciones principales, con:

<Ecuacion num="A.6.3-2" titulo="Deriva alternativa en pisos superiores">

$$
\Delta^{i}_{j}=\delta^{i}_{cm,j}-0.5\left[\frac{\left(\delta^{i-1}_{cm,j}-\delta^{i-2}_{cm,j}\right)\left(h_p^{i}+h_p^{i-1}\right)}{h_p^{i-1}}+\delta^{i-2}_{cm,j}\right]-0.5\,\delta^{i-1}_{cm,j}
$$

- $\delta^{i}_{cm,j}$, $\delta^{i-1}_{cm,j}$, $\delta^{i-2}_{cm,j}$: desplazamientos del centro de masa de los pisos $i$, $i-1$ e $i-2$.
- $h_p^{i}$, $h_p^{i-1}$: alturas de los pisos $i$ e $i-1$.

</Ecuacion>

**Cómo leerla (interpretación, no está explicada en el PDF).** El término entre corchetes es el desplazamiento que tendría el nivel $i$ si el perfil de desplazamientos de los dos pisos inferiores se **prolongara en línea recta** hasta ese nivel. La ecuación resta de $\delta^i$ el **promedio** entre esa extrapolación y el desplazamiento del piso $i-1$: en lugar de medir el "salto" completo entre pisos, mide cuánto se aparta el piso $i$ de la tendencia de los de abajo. Si el perfil fuera una **recta**, la fórmula da exactamente la **mitad** de la deriva convencional. Es la forma de no penalizar la rotación de conjunto (como la flexión de un muro en voladizo) en los pisos altos.

<Detalle titulo="Ejemplo numérico de A.6.3-2">

Edificio de muros de 10 pisos con $h_p$ = 3.0 m en todos los pisos, regular y con $Q_i$ < 0.10. En el piso 9 (por encima de 2/3 de la altura): $\delta^{7}$ = {alt.d2} mm, $\delta^{8}$ = {alt.d1} mm y $\delta^{9}$ = {alt.di} mm.

- Deriva convencional (A.6.3.1.1): {alt.di} − {alt.d1} = **{alt.conv} mm** (= {f(alt.conv / 3000 * 100, 2)} % de $h_p$).
- Extrapolación a $i$: {alt.d2} + ({alt.d1} − {alt.d2})(3 + 3)/3 = {f(alt.extrapol, 0)} mm.
- Deriva alternativa: {alt.di} − 0.5 × {f(alt.extrapol, 0)} − 0.5 × {alt.d1} = **{f(alt.delta, 1)} mm** (= {f(alt.razon * 100, 2)} % de $h_p$).

Control de coherencia: con un perfil recto 10–20–30 mm, la deriva convencional es {alt.rectConv} mm y la alternativa {f(alt.rect, 1)} mm (la mitad).

</Detalle>

## A.6.4 — Límites de la deriva

La deriva máxima de **cualquier piso**, obtenida según A.6.3.1, no puede exceder los límites de la Tabla A.6.4-1, expresados como porcentaje de la altura de piso $h_{pi}$ (<NormaRef s="A.6.4.1" pag="A-76" />):

## A.6.5 — Separación entre estructuras adyacentes

### A.6.5.1 — Dentro de la misma construcción

Todas las partes de la estructura deben actuar como **una unidad integral**, a menos que se separen una distancia suficiente para evitar el choque dañino entre partes. La distancia mínima de separación se obtiene **sumando el valor absoluto de los desplazamientos totales** de A.6.2.1 de cada una de las porciones, en la dirección perpendicular a la junta, salvo que se tomen medidas para que no haya daño con una distancia menor (<NormaRef s="A.6.5.1" pag="A-77" />).

### A.6.5.2 — Entre edificaciones vecinas

#### Alcance (A.6.5.2.1)

- **(a)** En municipios en **zona de amenaza sísmica baja** no se requiere separación sísmica entre vecinas.
- **(b)** Solo aplica a licencias de **edificaciones nuevas** solicitadas por primera vez después de adoptar el Reglamento.
- **(c)** **No** aplica a edificaciones en trámite de **reconocimiento**.
- **(d)** Para **rehabilitación sísmica** de edificaciones existentes aplican los requisitos de A.10.7.
- **(e)** El municipio o distrito puede **modificar** estos requisitos siempre que los resultantes **no sean menores** que los dados aquí.

#### Definiciones (A.6.5.2.2)

Las definiciones de altura del piso, altura de la edificación en la colindancia, cerramiento, coincidencia de las losas en la colindancia, nivel de un piso, número de pisos aéreos y separación sísmica en la colindancia están en el Capítulo A.13. Si el terreno es **inclinado** en la colindancia, hay **diferentes alturas de piso** o **diferente número de pisos aéreos**, se usa la altura de piso o el número de pisos que conduzca a la **mayor** separación sísmica.

#### Separación con el paramento del lote (A.6.5.2.3)

- **(a) Vía pública o zona verde pública**: no se requiere separación sísmica en ese costado (no exime de los retrocesos urbanísticos).
- **(b) Cerramiento**: si hay un cerramiento y la edificación nueva está separada de él más que lo señalado para el **piso crítico** en la Tabla A.6.5-1, no se requiere separación sísmica con el paramento.
- **(c)** Edificaciones con **uno o dos pisos aéreos** en la colindancia no requieren separación.
- **(d)** Con **más de dos pisos** aéreos: hasta tres pisos, ninguna separación si no hay vecino existente o si las losas coinciden; **1 %** de la altura de la edificación nueva si las losas no coinciden. Con más de tres pisos, **2 %** si las losas coinciden, **3 %** si no coinciden y **1 %** si no hay vecino (o es solo un cerramiento).
- **(e)** En cada piso, la separación es la distancia horizontal, perpendicular al plano vertical del lindero, medida desde la losa hasta ese plano, igual al **coeficiente de la tabla × la altura del piso sobre el terreno**.
- **(f)** Evitar que se depositen **materiales extraños** en la separación y colocar protección contra el **agua lluvia**.
- **(g)** En **reforzamiento y rehabilitación** el diseñador debe dejar constancia de que estudió el efecto de la interacción con las vecinas y tomó medidas (A.10.1.7).
- **(h)** El **paramento** y la separación requerida deben quedar **claramente indicados en los planos arquitectónicos** presentados a la curaduría o autoridad para la licencia.

<Callout tipo="practica" titulo="Qué significa en la práctica">
La separación **crece con la altura**: el primer piso casi puede estar sobre el lindero y la cubierta debe retirarse el 1 %, 2 % o 3 % de $h_n$. Y en un lote con vecino existente que **no dejó** separación, el vecino manda: de si las losas coinciden o no depende que se pida el 2 % o el 3 %.
</Callout>

## Errores comunes

<Callout tipo="error" titulo="Qué suele salir mal">
- **Calcular desplazamientos con fuerzas ya divididas por $R$**: las derivas se obtienen con $V_i$ sin dividir por $R$.
- **Olvidar P-Delta** cuando $Q_i > 0.10$, o ignorar que $Q_i > 0.30$ obliga a rigidizar.
- **Combinar primero las deflexiones modales** y restar después: se subestima la deriva (A.5.4.4).
- **Medir la deriva solo en el centro de masa** cuando hay irregularidad torsional 1aP/1bP: hay que revisar los puntos del piso (A.6.3-1).
- **Usar la forma alternativa A.6.3-2** sin cumplir las **cinco** condiciones (≥ 10 pisos, solo sobre 2/3 de la altura, no pórtico, regular y $Q_i$ < 0.10).
- **Aplicar el factor 0.7** con un modelo de secciones brutas.
- **Usar el límite de 1.0 % en mampostería poco esbelta** (el límite es 0.5 %).
- **Aplicar la separación sísmica con el $h_n$ de la cubierta en todos los pisos**: la separación depende de la altura de cada piso.
- **Olvidar indicar el paramento y la separación** en los planos arquitectónicos de la licencia.
</Callout>

## Resumen en una línea

**Calcula $\delta_{cm}$ (con fuerzas sin dividir por $R$) + torsión + P-Delta ($Q_i$ > 0.10) → deriva = diferencia entre pisos consecutivos → compárala con 1.0 % de $h_{pi}$ (0.5 % en mampostería poco esbelta; ×0.7 si hay secciones fisuradas) → y retira la edificación del lindero 1 %, 2 % o 3 % de la altura en cada piso según la Tabla A.6.5-1.**
